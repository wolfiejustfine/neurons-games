ОЗВУЧКА ИГР «НЕЙРОНЫ» — ПАКЕТ ДЛЯ ЗАПИСИ

Голос: один взрослый русскоязычный рассказчик на первый выпуск.
Предлагаемый вариант: тёплый женский голос, естественная разговорная подача.
Мужской голос с теми же качествами тоже подойдёт. Сначала выбираем по образцам.
Героев пока не озвучиваем разными голосами: рассказчик помогает ребёнку в каждой игре.

Подача: спокойно, доброжелательно, чуть медленнее обычной речи.
Истории — с лёгким интересом; инструкции — чётко и без спешки.
Пауза между действиями около половины секунды. В загадках не выделять голосом ответ.
Без сюсюканья, театрального восторга, музыки, звуков и дополнительных слов.
Слова из кавычек произносить обычным голосом; не читать «открываются кавычки».
Имена Ньют, Джейс, Арис, Рэн, Винч и название Мозгополис проверить на пробной записи.

СНАЧАЛА ТРИ ОБРАЗЦА
1. story-shadows.mp3 — короткая история, проверяем теплоту и естественность.
2. guide-shadows-01.mp3 — правила, проверяем разборчивость и паузы между действиями.
3. riddle-cat.mp3 — загадка, проверяем интонацию без подсказки ответа.
Точный текст каждого образца и остальных реплик — в script.txt и script.csv.
После выбора звучания записать остальные реплики приоритета 1. В файлах с together в имени есть отдельные правила и задания для игры со взрослым. Общие для обоих режимов реплики записать один раз.
Приоритет 2 — подсказки, названия картинок и отдельные примеры: вторым пакетом.
Одинаковые тексты записываются один раз, даже если звучат в нескольких уровнях.

ФОРМАТ
Каждая строка — отдельный MP3, имя файла строго из столбца «Файл».
Желательно моно, без длинной тишины в начале и конце, без перегруза.
Экспорт 44,1 кГц / 128 кбит/с подходит; при необходимости подготовим облегчённые копии.
Не объединять весь пакет в один длинный файл.
Все файлы можно сложить в одну папку и передать одним ZIP.

КАК ПОДКЛЮЧАЕТСЯ
В игре предусмотрены готовые MP3. Ключи ElevenLabs и доступ к аккаунту не нужны.
Сейчас новых записей ещё нет: системный голос и черновые загадки остаются резервом.
После получения файлов: npm run voice:import -- "путь к папке" --check,
затем npm run voice:import -- "путь к папке" и npm run build.
Каждая запись привязана к точному тексту. После изменения текста нужно обновить пакет
командой npm run voice:script и записать изменённые реплики заново.

Если команда требует именно живого диктора, эти же тексты можно записать с Настей
или Максимом. Озвучка ElevenLabs будет синтезированной; качество оцениваем по образцам.
