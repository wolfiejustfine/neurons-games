# Игры Мозгополиса

[Открыть игры](https://wolfiejustfine.github.io/neurons-games/) ·
[Репозиторий](https://github.com/wolfiejustfine/neurons-games)

Четырнадцать игр во вселенной «Нейроны» по предложениям Анастасии
Левшиной. Основная платформа — мобильный браузер в портретной ориентации.

Коллекция включает тени, анаграммы, шифры, корректурную пробу, будильники,
перестановку предметов, сортировку жидкостей, лабиринты с кодами,
лабиринт с сортировкой, распутывание проводов, поиск забытых вещей,
математическую раскраску, колесо загадок и ранее созданные таблицы Шульте.
В первых тринадцати играх по восемь заданий, в Шульте — 30 уровней:
всего 134 задания и отдельная ежедневная таблица Шульте.

## Локальный запуск

Требуется Node.js 22.20 или совместимая новая версия.

~~~sh
git clone https://github.com/wolfiejustfine/neurons-games.git
cd neurons-games
npm ci
npm run dev
~~~

На Windows при ограничении PowerShell используйте npm.cmd.
Файл start-games.cmd собирает актуальную версию и запускает её на порту 4173.

~~~sh
npm test
npm run build
npm run preview
~~~

npm test проверяет решаемость пробирок, допустимость ходов, связность
лабиринтов и положение стрелок часов. build сначала проверяет TypeScript,
затем создаёт статические файлы в dist.

Чтобы открыть коллекцию на телефоне, запустите npm run preview и откройте
показанный Network-адрес на устройстве в той же сети. При необходимости
разрешите доступ к выбранному порту в локальном межсетевом экране.

## Поведение первой версии

- Прогресс и настройка звука сохраняются в браузере на текущем устройстве.
- Каждое задание можно повторить или выбрать через номер задания вверху.
- Во время игры кнопка «Как играть» открывает правила в три шага.
  В правилах есть наглядный пример и кнопка «Послушать правила».
  Справка приостанавливает игровое поле и возвращает к той же попытке.
- Готовое поле остаётся видимым. Ребёнок сам нажимает «Дальше»;
  после сборки слова или пароля предлагается прочитать результат.
- Подсказка сначала напоминает правило, затем направляет внимание,
  а при повторном обращении показывает конкретную помощь.
- Если задание уже начато, кнопка «Ещё раз» сначала предлагает продолжить
  текущую попытку или начать заново.
- Перетаскивание букв, символов, часов и предметов дополнено выбором касаниями.
- В лабиринтах работают ведение пальцем, касания соседних клеток и стрелки.
- В пробирках доступны отмена хода и подсказка на основе решения текущего поля.
- В пробирках указан полный результат: каждый цвет в одной полной пробирке
  из четырёх слоёв, остальные пустые. Готовые пробирки отмечены галочками.
- В анаграммах кнопка «Что на картинке?» уточняет ожидаемое название;
  название показывается текстом и читается вслух при доступном голосе.
- В игре на память можно ещё раз посмотреть образец, сохранив расставленные
  вещи. В лабиринте сортировки винты и гвозди распределяются по подписанным
  ящикам со значками предметов.
- Кнопка чтения задания использует русский системный голос, если он доступен.
- На узком горизонтальном экране появляется предложение повернуть устройство.
- Первые задания начинаются с двух вариантов в тенях, двух предметов на
  память, четырёх знаков и одного провода. Нагрузка увеличивается постепенно.
- В часах отдельно вводятся целые часы, время после полудня и получасы;
  инструкции и пример соответствуют текущему этапу. Выбранные часы можно
  увеличить без потери уже назначенных встреч.
- В «Забытых вещах» нужно найти от трёх до шести предметов из списка
  в лаборатории Ньюта. На поле от шести до двенадцати предметов.
- «Цветные открытия» содержат рисунки робота и ракеты: сначала сложение
  до 10, затем вычитание и примеры до 20. Для ответа открывается отдельная
  цифровая клавиатура; системная клавиатура не перекрывает рисунок.
- «Колесо загадок» содержит 24 загадки с картинками-ответами и русскими
  MP3-записями. Загадку можно повторить или прочитать. Записи текущего
  задания подгружаются при открытии игры; главный экран их не загружает.
- «Таблицы Шульте» подключены целиком из предоставленного архива: 30 уровней,
  пять миров, таблица дня, серии, рекорды, спокойный режим и экран для родителей.
  Верхняя кнопка возвращает к другим играм. Карточка в каталоге читает прогресс
  из исходного сохранения shulte.v3; статистика остаётся в исходном формате.
- Production-сборка содержит PWA manifest и service worker. Главный экран
  сохраняется для работы без сети; код игр и их материалы кэшируются при
  посещении. Непосещённая игра может потребовать интернет.

Первая версия подготовлена для проверки на устройствах и содержательной
оценки заданий. Работа системной озвучки зависит от браузера и установленных
голосов. Автоматические проверки не заменяют наблюдение за тем, как ребёнок
понимает задания.

## Структура

- src/catalog.ts — игры, подводки и описания.
- src/games/ — тринадцать самостоятельных игровых механик.
- vendor/schulte/ — неизменённые исходники предоставленного архива Шульте.
- schulte/index.html — отдельный вход исходной игры с возвратом в коллекцию.
- public/schulte/ — исходные изображения и звуки Шульте; общие шрифты
  проверены по содержимому и используются из public/fonts/.
- assets/schulte-import.json — контрольные суммы архива и импортированных файлов.
- tests/reports/schulte.json — проверка 30 уровней, ежедневной таблицы,
  родительского экрана и совместимости сохранений.
- src/expansion.ts — задания поиска, арифметические примеры и 24 загадки.
- src/play/ — общие инструменты Phaser и сенсорного управления.
- src/rules.ts — правила головоломок и генерация лабиринтов.
- src/save.ts — локальный прогресс.
- public/art/ — облегчённые производные предоставленных изображений.
- public/props/ — предметы, создаваемые node tools/build-props.mjs.
- tests/qa-plan.json — перечень проверок интерфейса и поведения.
- tests/reports/mentor-fixes.json — повторная проверка всех 80 заданий
  после педагогического разбора.
- tests/reports/expansion.json — проверка новых игр и повторное
  прохождение всех 104 заданий на мобильном экране.
- assets/expansion-manifest.json — происхождение нового фона, промпт
  генерации и сведения о синтезированной озвучке.
- public/audio/ — MP3-записи загадок. Для их повторного создания экспортируйте
  RIDDLES из src/expansion.ts в assets/riddle-script.json и запустите
  tools/build-riddle-audio.ps1 (Windows, голос Microsoft Irina Desktop, ffmpeg).

Для размещения достаточно статического хостинга с HTTPS. Передавайте
содержимое dist целиком. Внешние сервисы и серверная база данных не нужны.

## Публикация на GitHub Pages

После каждого обновления ветки main GitHub Actions устанавливает зависимости
через npm ci, выполняет тесты, собирает проект и публикует содержимое dist.
Pull request запускает те же проверки без публикации. Настройка находится в
.github/workflows/pages.yml; в Settings → Pages выбран источник GitHub Actions.

Игры доступны по адресу https://wolfiejustfine.github.io/neurons-games/.
На телефоне можно добавить этот адрес на главный экран. Прогресс хранится
в браузере текущего устройства. Сохранения с localhost и других доменов
автоматически не переносятся. Если отдельная игра Шульте размещена на том же
домене GitHub Pages, её сохранение shulte.v3 доступно и коллекции.

В репозиторий входят исходники, игровые изображения, звуки и отчёты проверок.
Локальные зависимости node_modules, сборка dist и рабочая папка artifacts
исключены из Git. Исходные файлы OneDrive перечислены в манифестах; для
сборки достаточно включённых в репозиторий игровых материалов.

## Материалы

Персонажи, изображения мира и шрифт Neuronus предоставлены для проекта
«Нейроны». Их использование ограничено этим проектом. Rubik распространяется
по SIL Open Font License; Phaser — по MIT. Уведомления находятся в
public/licenses.

Исходные материалы пользователя перечислены в assets/source-manifest.json.
Настройки проекта и установленные скиллы описаны в AGENTS.md,
project-context.json и skills-lock.json.

На этапе расширения добавлена одна комната для поиска и два простых рисунка
для раскраски. Все тематические модификации и локации героев из документа
Насти остаются отдельным этапом наполнения.
